# Course React Application

This project is a full-stack CRUD application for course management developed with React for the frontend and Node.js with Express for the backend. The application allows users to manage courses by performing create, read, update, and delete operations.

## Features

- Create new courses
- Upload and store course images
- Retrieve and display all courses
- Update course information and images
- Delete existing courses
- Store course title, description, and image data
- MySQL database integration

## Technologies Used

### Frontend
- React
- JavaScript
- CSS

### Backend
- Node.js
- Express
- Multer
- MySQL2
- CORS

## Database

The project uses MySQL to store:

- Course title
- Course description
- Course image

## CRUD Operations

- **Create:** Add a new course with image, title, and description
- **Read:** Retrieve and display courses
- **Update:** Modify existing course data and images
- **Delete:** Remove courses from the database
